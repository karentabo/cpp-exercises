# C++ Exercises

# 

# This repository contains a collection of C++ exercises created to practice programming logic, data structures, input/output handling, loops, conditionals, arrays, and general problem-solving using the C++ language.

# 

# The purpose of this project is to strengthen fundamental programming skills through clean, organized, and structured solutions to beginner and intermediate problems.

# 

# 🚀 Features

# 

# Basic input and output (cin, cout)

# 

# Conditionals (if/else, switch)

# 

# Loop structures (for, while, do-while)

# 

# Arrays and data processing

# 

# Mathematical operations and averages

# 

# String handling with getline and buffer cleaning

# 

# Realistic, logic-based exercises
